# Step 5 – Category page restyle (no code)

The Category Page is **one shared Wix Stores page**. Every category uses it (All Products, Clothing, Bedding and so on), so styling it once covers all of them.

Keep it native: filters, sorting, paging, search and Google indexing all keep working.

**Open it:** Editor → **Page: Home ▾** → **Store Pages → Category Page**. Click the product gallery, then **Settings**.

Panel names vary a little between Wix versions. Look for the closest match.

## Colours (same as the homepage)
| | Hex |
|---|---|
| Chocolate (text, buttons) | `#3D2418` |
| Soft brown (small text) | `#7A5A4B` |
| Butter (hover, highlights) | `#FFD86B` / deep `#E9B320` |
| Linen (backgrounds) | `#FBF6EF` |
| Stitch line (borders) | `#EAD9C8` |

## 1. Page background
Click an empty area of the page (not the gallery) → **Change Page Background → Color** → `#FBF6EF`.
This replaces the grey left area with linen.

## 2. Settings → Layout
- **Products per row:** 4 on desktop.
- **Spacing between products:** 24 (columns) and 32 (rows).
- **Image ratio:** **Portrait 3:4** (or 4:5), which suits clothing.
- **Image resize / crop:** Crop / Fill.
- **Text alignment:** Left.
- **Products per page / Load more:** 24 + **Load More** button (or infinite scroll).

## 3. Settings → Display
- **Show:** Product name ✓, Price ✓, Ribbon ✓, Quick View ✓, **Add to Cart button** ✓.
- **Image hover effect:** **Swap image** (shows the second photo on hover). If that's not available, use **Zoom**.
- **Show product options** (sizes) on the card: ✓ if offered. Customers can then pick a size without opening the product.

## 4. Settings → Design
**Category title** ("All Products", purple now):
- Font **Fredoka**, size 36–40, colour `#3D2418`, left-aligned if offered.

**Product card:**
- Background white, **corners 20**, border none.
- Shadow off, or a very soft one.

**Product image:**
- Corners **16**.

**Product name:**
- Figtree/Poppins 15, colour `#3D2418`.
- **2 lines max** if there's a setting for it.

**Price:**
- Fredoka 17, colour `#3D2418`.
- Strike-through price `#7A5A4B`.

**Ribbon** ("New", "Sale"):
- Background `#3D2418`, text white, corners 999.

**Add to Cart button:**
- Fill `#3D2418`, text white, corners **999**.
- Hover: fill `#E9B320`, text `#3D2418`.
- Text: **Add to cart**.

**Quick View:**
- Background white, text `#3D2418`.

**Filters sidebar** ("Browse by" / "Filter by"):
- Titles: Fredoka 18, `#3D2418`.
- Options: 15, `#7A5A4B`.
- Selected / link colour: `#3D2418` (now purple).
- Price slider colour: `#3D2418`.
- Dividers: `#EAD9C8`.

**Sort dropdown and "377 products":**
- `#7A5A4B`.

**Load More button:**
- Outline 2 px `#3D2418`, text `#3D2418`, corners 999.
- Hover fill `#FFD86B`.

## 5. Browse by: show the real categories
"Browse by" shows only **All Products**. Under **Settings → Filters / Categories**, turn on **Show categories**. Select the main ones:
- **Clothing**
- **Bedding & Comfort**
- **Accessories**
- **Essentials**
- **Ethnic Wears**
- **Kids Combo Pack**
- the **age** categories (0-3 Month … 2-3 Years)

Now shoppers can switch category from the sidebar.

Under **Filter by**, keep **Price** and **Size**. Add **Color** only if the products have colour options.

## 6. Mobile (phone icon)
- **Products per row:** **2**, spacing 12.
- **Filters:** use the "Filter & Sort" button (default on mobile). Style it with a chocolate background, white text and corners 999.
- **Title:** size 28.

## 7. Check
Save, then open a fresh **Test Site**:
- Open **Shop All**, **Clothing** and **Ethnic Wears**. They should all have the same style.
- Hover a product: the second image or zoom shows. Quick View opens.
- Add to Cart works.
- Filters and sorting work.
- On a phone: 2 columns, and Filter & Sort opens.

Then it's the **Product page** (Step 6).
